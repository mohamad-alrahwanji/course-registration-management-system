# Course Registration Management System

A desktop course registration management application built with C#, Windows Forms, ADO.NET, and SQL Server.

## Features

- User authentication
- Student management
- Course management
- Class management
- Course registration and withdrawal
- Registration history
- Registration reports
- Student and administrator dashboards

## Technologies

- C#
- .NET
- Windows Forms
- ADO.NET
- SQL Server

## Project Structure

- `CourseRegistrationManagementSystem` - Windows Forms user interface
- `CourseRegistration.BusinessLogic` - application logic and validation
- `CourseRegistration.DataAccess` - database access and repositories
- `CourseRegistration.Models` - application models
